---
name: Java runtime
description: Supported Java toolchain for compiling and running the console app in this workspace.
---

Use the Replit Java Tools with GraalVM 22.3 module for Java compilation and execution.

**Why:** A plain Java runtime was not present initially, and the available supported module provides `javac` and `java` together.

**How to apply:** Keep the Java module aligned with the project run configuration before compiling `Main.java`.
